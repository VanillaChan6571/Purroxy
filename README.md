# Purroxy

Purroxy is using parts of Velocity MC and is licensed under the GPLv3 license.

## Goals

* Dynamic Add/Remove Servers
* Grouped Server Links
* Seamless Hub + Lobby Transfers
  
## Building

Purroxy is built with [Gradle](https://gradle.org). We recommend using the
wrapper script (`./gradlew`) as our CI builds using it.

It is sufficient to run `./gradlew build` to run the full build cycle.

## Running

Once you've built Purroxy, you can copy and run the `-all` JAR from
`proxy/build/libs`. Purroxy will generate a default configuration file
and you can configure it from there.
